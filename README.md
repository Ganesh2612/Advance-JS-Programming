# Advance-JS-Programming

# 📚 Data Structures & Algorithms with Modern JavaScript

## 🧠 Overview

This repository provides a comprehensive exploration of **JavaScript Data Structures**, **Object-Oriented Programming**, and **Asynchronous Programming** techniques. It combines foundational principles with advanced patterns to help developers understand and practice JavaScript at a deeper level.

---

## 🔷 Topics Covered

### 🧱 Object-Oriented Programming in JavaScript

- **Objects & Classes**  
  Understanding object creation, manipulation, and encapsulation.

- **Object References & Copying**  
  Deep vs shallow copies, and implications on memory.

- **Garbage Collection**  
  How JavaScript manages memory automatically.

- **Object Methods & `this` Keyword**  
  Binding, context, and method invocation patterns.

- **Constructors & `new` Operator**  
  Creating objects using constructor functions and ES6 classes.

- **Optional Chaining (`?.`)**  
  Safe property access in deeply nested structures.

- **Object-to-Primitive Conversion**  
  Customizing object conversion using `valueOf()` and `toString()`.

- **Property Flags & Descriptors**  
  Controlling enumerability, writability, and configurability.

- **Getters & Setters**  
  Creating computed properties and controlled access.

- **Prototypes & Inheritance**  
  Delegation model using `[[Prototype]]`, `__proto__`, and `Object.create()`.

- **Native Prototypes & Custom Classes**  
  Extending built-in behavior and creating reusable abstractions.

- **Class Inheritance**  
  Using `extends`, `super()`, and polymorphism.

- **Extending Built-in Classes**  
  Enhancing built-in functionality like `Array`, `Error`, etc.

---

### ⏳ Asynchronous JavaScript

- **Promises & Chaining**  
  Composing asynchronous tasks with `.then()` and `.catch()`.

- **Promise API**  
  `Promise.all`, `Promise.race`, `Promise.any`, `Promise.allSettled`.

- **Error Handling in Promises**  
  Gracefully managing asynchronous errors.

- **Custom Errors & Extending `Error`**  
  Creating and handling domain-specific exceptions.

- **Promisification**  
  Converting callback-based APIs into Promises.

- **Async/Await**  
  Writing asynchronous code in synchronous style.

- **Async Iteration & Generators**  
  Iterating over asynchronous data streams using `for await...of`.

---

### 🧩 Functional Programming Concepts

- **Currying**  
  Transforming functions for partial application.

- **Callbacks**  
  Traditional asynchronous pattern and callback hell mitigation.

- **Microtasks**  
  Event loop, queueing via `Promise.resolve().then()`.

- **Hoisting**  
  Understanding variable/function declaration behavior.
